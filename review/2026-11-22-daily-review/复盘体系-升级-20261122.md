# 每日复盘体系升级（2026-11-22）——GitHub 学习 + 落地

> 目标：把「每日复盘」从「今天赚了还是亏了」升级为「这套方法是否可持续」。
> 方法：检索 GitHub 上 trading journal / postmortem / review 类项目，抽取指标口径，落到 `stocklens/review.py`。

### 共性结论

1. **以"平仓交易"为单位统计**（round-trip），而不是按天看总盈亏；
2. 核心 KPI：胜率、平均盈亏、**利润因子（profit factor）**、**单笔期望值**、最大回撤；
3. 复盘要回答「**规则有没有被执行**」（合规/缺勤/违规），不只是数字；
4. 记录要能长期复用（周报/月报/样本累积），并支持导出；
5. 本地/私有优先，不依赖第三方 SaaS。

## 二、我们改了什么（已上线代码）

### 新模块 `stocklens/review.py`

对 A/B/C 三个实例分别计算（今日 + 累计）：

| 指标 | 说明 |
|---|---|
| 平仓笔数 / 胜率 | 只看有 `pnl` 的卖出 |
| 平均盈利 / 平均亏损 | 分赢家和输家 |
| 利润因子 | 总盈利 ÷ 总亏损（>1 才有优势） |
| 单笔期望值 | 平均每笔盈亏（最直观的"这套方法赚不赚钱"） |
| 最大回撤 | equity 序列的峰谷回撤（含发生区间） |
| 累计盈亏 / 收益率 / 费用 | 含手续费 |
| 今日买卖笔数 / 今日盈亏 | 当日表现 |
| 逾期未卖 | 当前持仓里 `sell_due` 已过的（对应"到期必卖"纪律） |
| 基准 | 上证指数近 10 日涨跌 |

产物：`_data/review_stats.json`；CLI：`python -X utf8 -m stocklens.review`

### 归因报告升级（`postmortem_{date}.md`）

原有「策略/执行/市场」归因表保持不变，**末尾新增「交易质量总览（累计）」**：

```
| 实例 | 平仓 | 胜率 | 期望/笔 | 盈亏比 | 累计盈亏 | 最大回撤 |
| A | 0 | — | — | — | 0 | -0.86% |
| B | 2 | 0.0% | -394.21 | 0.0 | -788.43 | -0.56% |
| C | 0 | — | — | — | 0 | 0.0% |
- 合计：平仓 2 笔，胜率 0.0%，累计 -788.43 元（-1.61%）
- 基准：上证指数近 10 日 -3.16%
```

### 收盘推送升级（企业微信 15:10）

收盘核对末尾多一行复盘摘要：

```
> 复盘：累计平仓 2 笔 · 胜率 0.0% · 累计 -788.43 元（-1.61%） · 上证近 10 日 -3.16%
```

### 测试

`tests/test_review.py` 5 项：指标计算、空 equity 兜底、合计、文本摘要、save=False 不覆盖生产文件。

## 三、升级前后对比

| 维度 | 升级前 | 升级后 |
|---|---|---|
| 看今天 | 权益/盈亏/成交 | 权益/盈亏/成交 + 今日买卖笔数 |
| 看方法 | 无统一指标 | 胜率/期望/利润因子/回撤 |
| 看纪律 | 缺勤/违规/兜底（当日） | 额外「逾期未卖」 |
| 看基准 | 上证同期（归因用） | 明确展示近 10 日基准 |
| 入口 | 只写 md | md + `review_stats.json` + 微信推送摘要 |
| 长期 | 每次重新看账本 | 指标口径固定，可累计对比 |

## 四、下一步（待做，按优先级）

1. **周报/月报**：复用同一套指标做滚动窗口（本周 vs 上周），周五推送
2. **交易标签**：给每笔卖单打「策略/执行/市场」主因标签，统计各原因占比
3. **基准 alpha**：按持仓市值加权 vs 沪深300，算超额收益（而不只是指数涨跌）
4. **权益曲线图**：已有 `wecom_chart`，可把回撤区间标在图里
5. **AI 复盘日记**：每天一段「今天发生了什么/为什么/明天注意」（规则模板先行，后续接 LLM）
6. **导出 CSV**：给 Excel/WorkBuddy/豆包做二次分析
7. **复盘问答**：把这套指标接进豆包/WorkBuddy 智能体（问"这周复盘怎么样"直接回答）

> 口径说明：所有指标以账本 `sim.json` 的成交记录为准；没有 `pnl` 的卖出不计入平仓统计；样本 <20 笔前只做记录、不据此改规则（延续 charter 硬约束）。

## 五、2026-11-22 加更：个股复盘（逐票）

| 板块 | 内容 |
